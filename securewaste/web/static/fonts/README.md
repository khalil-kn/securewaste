# Fonts (self-hosted)

The content security policy only allows resources from this server, and SecureWaste never contacts outside
services, so the fonts live here instead of loading from Google Fonts.

| File | Font | Source | Licence |
|---|---|---|---|
| `public-sans-latin-wght-normal.woff2` | Public Sans (variable, Latin) | `@fontsource-variable/public-sans` 5.3.0 | SIL OFL 1.1, `PublicSans-OFL.txt` |
| `ibm-plex-mono-latin-400-normal.woff2`, `-500-` | IBM Plex Mono (Latin) | `@fontsource/ibm-plex-mono` 5.3.0 | SIL OFL 1.1, `IBMPlexMono-OFL.txt` |

Public Sans is used for everything people read; IBM Plex Mono only for masked values, IDs and hashes.
